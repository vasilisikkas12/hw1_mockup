# SmartPantry 🍏

## Περιγραφή Εφαρμογής (HW 1: Interactive Mockup)
Το **SmartPantry** είναι μια καινοτόμος εφαρμογή για κινητά, σχεδιασμένη να καταπολεμά τη σπατάλη τροφίμων (food waste) στα νοικοκυριά. Λειτουργεί ως ένας έξυπνος ψηφιακός βοηθός κουζίνας που βοηθά τους χρήστες να παρακολουθούν τα τρόφιμα στο ψυγείο τους και να τα καταναλώνουν πριν αλλοιωθούν. 

Η ιδέα είναι πρωτότυπη και επικεντρώνεται σε ένα πραγματικό, καθημερινό πρόβλημα, με προοπτική εξέλιξης καθ' όλη τη διάρκεια του εξαμήνου. Αυτό το repository περιέχει το διαδραστικό πρωτότυπο (clickable mockup) της εφαρμογής.

## Βασικές Λειτουργικότητες (AI Features)
Η εφαρμογή ικανοποιεί τις απαιτήσεις της εργασίας ενσωματώνοντας και τα δύο προτεινόμενα συστήματα:

1. **Προγνωστικό Μοντέλο (Predictive Model):** 
   Το mockup προσομοιώνει ένα μοντέλο που εκτιμά τον υπολειπόμενο χρόνο ζωής των φρέσκων τροφίμων. Λαμβάνει ως είσοδο το είδος του τροφίμου και τις ημέρες που ήδη βρίσκεται στο ψυγείο, και προβλέπει πόσες μέρες απομένουν μέχρι την πιθανή αλλοίωσή του, βγάζοντας τις αντίστοιχες προειδοποιήσεις.

2. **Σύστημα Προτάσεων (Recommender System):**
   Προσομοιώνεται ένας αλγόριθμος συστάσεων που προτείνει συνταγές με βάση τα υλικά που ο χρήστης δηλώνει ότι έχει διαθέσιμα (και τα οποία ιδανικά λήγουν σύντομα). Αντί για γενικές συνταγές, το σύστημα προτείνει στοχευμένα γεύματα για τη βέλτιστη αξιοποίηση των υλικών.

## Τεχνολογία Υλοποίησης
Το διαδραστικό mockup δημιουργήθηκε με τη χρήση της βιβλιοθήκης **Streamlit** σε Python. Είναι ένα clickable preview που επιτρέπει στον χρήστη να αλληλεπιδράσει με το περιβάλλον (επιλογή υλικών, χρήση sliders, κουμπιά) για να κατανοήσει τη λειτουργικότητα, χωρίς να εκτελούνται πολύπλοκα μοντέλα μηχανικής μάθησης στο παρασκήνιο (όπως ακριβώς απαιτείται για το HW 1).
